# Dynamic Programming

Optimization technique: solve subproblems once, store results.

## Approaches
- Top-down (memoization) — recursion + cache
- Bottom-up (tabulation) — iterative, fill table

## Patterns
- 1D DP (climbing stairs, house robber)
- 2D DP (grid paths, edit distance)
- Subsequences (LCS, LIS)
- Knapsack variants
- Interval DP
