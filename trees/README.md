# Trees

Hierarchical structure. Binary trees and BSTs are most common.

## Patterns
- DFS: inorder, preorder, postorder
- BFS: level-order traversal
- Recursion on left/right subtree
- BST properties (left < root < right)

## Complexities (Balanced BST)
| Operation | Time |
|-----------|------|
| Search | O(log n) |
| Insert | O(log n) |
| Delete | O(log n) |
