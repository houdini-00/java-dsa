# Linked Lists

Dynamic linear structure with nodes connected via pointers.

## Patterns
- Traversal and manipulation
- Fast & slow pointers (Floyd's cycle detection)
- Reversal (iterative and recursive)
- Merge two lists
- Finding middle

## Complexities
| Operation | Time |
|-----------|------|
| Access | O(n) |
| Insert at head | O(1) |
| Insert at tail | O(n) |
| Delete | O(n) |
