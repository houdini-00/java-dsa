# Stack & Queue

## Stack
LIFO. Backed by arrays or linked lists.

## Queue
FIFO. Use ArrayDeque in Java.

## Patterns
- Balanced parentheses
- Monotonic stack (next greater/smaller element)
- BFS with queue
- Implement one using the other

## Complexities
| Operation | Time |
|-----------|------|
| Push/Pop/Peek | O(1) |
| Enqueue/Dequeue | O(1) |
