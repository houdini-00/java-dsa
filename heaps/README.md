# Heaps

Complete binary tree. Min-heap or max-heap.
Java: use PriorityQueue (min-heap by default).

## Patterns
- Top K elements
- Kth largest/smallest
- Merge K sorted lists
- Running median

## Complexities
| Operation | Time |
|-----------|------|
| Insert | O(log n) |
| Delete min/max | O(log n) |
| Peek min/max | O(1) |
| Build heap | O(n) |
