# Hashing

Key-value lookups in O(1) average time.
Java: HashMap, HashSet, LinkedHashMap.

## Patterns
- Frequency counting
- Seen-before / duplicate detection
- Grouping (anagrams, equivalents)
- Two-sum style lookups

## Complexities
| Operation | Time (avg) |
|-----------|------------|
| Insert | O(1) |
| Lookup | O(1) |
| Delete | O(1) |
