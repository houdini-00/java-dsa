# Strings

Immutable character sequences. Many array techniques apply directly.

## Patterns
- Character frequency maps
- Two pointers
- Sliding window
- Palindrome checks
- Anagram detection

## Complexities
| Operation | Time |
|-----------|------|
| Access char | O(1) |
| Substring | O(n) |
| Comparison | O(n) |
