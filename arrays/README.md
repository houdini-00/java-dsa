# Arrays

Linear data structure with index-based access.

## Patterns
- Brute force / linear scan
- Two pointers
- Sliding window
- Prefix sums
- Sorting and binary search on arrays

## Complexities
| Operation | Time |
|-----------|------|
| Access | O(1) |
| Search (unsorted) | O(n) |
| Search (sorted) | O(log n) |
| Insert/Delete | O(n) |
